# Security policy

## Scope

TripSignal is a local demonstration prototype, not a hardened service. It has no user authentication, authorization, or production deployment controls. Keep it bound to loopback and do not submit private travel details.

## Reporting a vulnerability

Please do not post credentials, exploit details, or personal data in a public issue. Contact the repository owner privately through the contact method listed on the GitHub profile. Include the affected component, impact, and a concise reproduction when possible.

Do not include API tokens, `.env` contents, cached response data, or passenger information in a report.
